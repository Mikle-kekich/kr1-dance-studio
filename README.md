# Танцевальная студия — контрольная работа №1 (вариант 89)

Консольная информационная система на **Java 21 + JDBC + PostgreSQL**.
Предметная область: танцевальная студия, основная сущность — **«Запись на занятие»**.
Многослойная архитектура: `Console UI → Service → Repository (JDBC) → PostgreSQL`.

## Что сдавать и где это лежит

| Требование КР №1 | Файл / папка |
|---|---|
| Исходный код Java-проекта | `src/main/java/ru/mirea/dancestudio/` |
| Файл `pom.xml` | `pom.xml` |

## Требования

* JDK 21 или новее (`java -version`);
* Maven 3.9+ (или Maven, встроенный в IntelliJ IDEA);
* PostgreSQL 14+ (проверено на 17).

## Запуск

**1. Укажите параметры подключения к PostgreSQL.** Пароль в коде не хранится. Достаточно одного способа:

* отредактировать `src/main/resources/database.properties` (`db.url`, `db.user`, `db.password`);
* или положить файл `database.properties` с теми же ключами рядом с программой;
* или задать переменные окружения `DB_URL`, `DB_USER`, `DB_PASSWORD` (у них наивысший приоритет).

**2. Соберите проект** (при сборке выполняются 69 модульных тестов; без них добавьте `-DskipTests`):

```bash
mvn clean package
```

**3. Запустите программу:**

```bash
run.bat
```

или вручную: `java -Dapp.encoding=UTF-8 -jar target/dance-studio.jar`.

При первом запуске программа сама предложит создать базу `dance_studio`, таблицы и загрузить тестовые данные.
Пересоздать таблицы с тестовыми данными позже можно параметром `--init-db` (все данные будут заменены, программа спросит подтверждение).

**Запуск из IntelliJ IDEA (самый простой способ):** откройте `pom.xml` как проект, дождитесь загрузки Maven-зависимостей и запустите класс `ru.mirea.dancestudio.Main` (зелёный треугольник рядом с `main`). Сборка в IDE: вкладка Maven → Lifecycle → `package`.

Если `java` не найдена в `PATH`, задайте переменную `JAVA_HOME` (подойдёт JDK, встроенный в IntelliJ: папка `jbr` внутри каталога IDE) — `run.bat` её использует.

### Создание базы вручную (без мастера первого запуска)

```bash
psql -U postgres -f sql/00_create_database.sql
psql -U postgres -d dance_studio -f sql/01_schema.sql
psql -U postgres -d dance_studio -f sql/02_test_data.sql
```

То же можно выполнить в pgAdmin (Query Tool): сначала `00`, затем — подключившись к базе `dance_studio` — `01` и `02`.

## Бизнес-правила (реализованы в слое Service)

| № | Правило | Где в коде |
|---|---|---|
| БП-1 | Данные клиента корректны: ФИО (не менее двух слов, только буквы), телефон, email, дата рождения, возраст от 3 до 100 лет | `ClientService` |
| БП-2 | Телефон и email клиента уникальны (дополнительно `UNIQUE` в БД) | `ClientService` |
| БП-3 | Нельзя записать несуществующего клиента на несуществующее занятие | `EnrollmentService.create` |
| БП-4 | Нельзя записаться на занятие, которое уже началось или прошло | `EnrollmentRules` |
| БП-5 | Возраст клиента не ниже минимального возраста занятия | `EnrollmentRules` |
| БП-6 | Нельзя дважды записаться на одно занятие (отменённая запись не мешает записаться снова) | `EnrollmentRules`, частичный `UNIQUE INDEX` |
| БП-7 | Нельзя записаться на занятие без свободных мест | `EnrollmentRules` |
| БП-8 | Стоимость не отрицательна (не более 2 знаков после запятой), комментарий до 500 символов | `Validation` |
| БП-9 | Завершённую и отменённую запись изменять нельзя | `EnrollmentService.update` |
| БП-10 | У подтверждённой записи нельзя снять отметку об оплате | `EnrollmentService.update` |
| БП-11 | Разрешены только переходы статусов `CREATED → CONFIRMED / CANCELLED`, `CONFIRMED → COMPLETED / CANCELLED` | `EnrollmentStatus`, `EnrollmentRules` |
| БП-12 | Подтвердить можно только оплаченную запись и только до начала занятия | `EnrollmentRules` |
| БП-13 | Завершить запись можно только после начала занятия | `EnrollmentRules` |
| БП-14 | Удалять можно только записи «Создана» и «Отменена» (история посещений сохраняется) | `EnrollmentRules` |
| БП-15 | Данные занятия корректны; новое занятие нельзя создать в прошлом | `DanceClassService` |
| БП-16 | Вместимость занятия нельзя сделать меньше числа занятых мест | `DanceClassService` |
| БП-17 | Нельзя удалить занятие, на которое есть записи | `DanceClassService` |
| БП-18 | Нельзя удалить клиента, у которого есть записи | `ClientService` |

## Обработка ошибок

Программа не завершается аварийно: любая ошибка в действии меню превращается в сообщение, и пользователь возвращается в меню.

* текст вместо числа — `Ошибка: ID должен быть целым числом.`, вопрос повторяется;
* запись с таким ID отсутствует — `EntityNotFoundException`;
* нарушение бизнес-правила — `BusinessException`;
* база недоступна или неверный пароль — `DatabaseException`: при запуске предлагается повторить попытку;
* ошибка SQL — `SqlErrors` превращает `SQLException` (по коду SQLSTATE) в понятное сообщение без стека вызовов.

## Архитектура

```
ui (меню, ввод/вывод)  ->  service (бизнес-правила)  ->  repository (SQL, JDBC)  ->  PostgreSQL
                                     |                                     |
                                   model  <----------------------------  exception, util
```

* `model` — сущности `Client`, `DanceClass`, `Enrollment` (наследники `BaseEntity`), перечисления `EnrollmentStatus`, `DanceStyle`, `DanceLevel`, интерфейс `Exportable`;
* `repository` — интерфейсы `CrudRepository`, `ClientRepository`, … и их JDBC-реализации; общий код JDBC — в `JdbcSupport`;
* `service` — `ClientService`, `DanceClassService`, `EnrollmentService`, `EnrollmentQueryService`, `StatisticsService`, `ExportService`;
* `ui` — интерфейс `Menu`, `AbstractMenu` и конкретные меню; SQL в меню нет;
* `util` — `DatabaseManager`, `ExcelExporter`, `CsvExporter`, `TablePrinter`, `SqlErrors`;
* `exception` — собственные исключения.

## Возможные проблемы

* **Русские буквы отображаются «крякозябрами».** Программа сама определяет кодировку консоли. Если это не сработало, выполните `chcp 65001` и запустите с параметром `-Dapp.encoding=UTF-8` (`java -Dapp.encoding=UTF-8 -jar target/dance-studio.jar`) либо запускайте из IntelliJ IDEA.
* **`password authentication failed`.** Проверьте `db.user` и `db.password` в `database.properties`.
* **`Connection refused`.** Служба PostgreSQL не запущена или указан другой порт в `db.url`.
* **Поиск не находит русский текст без учёта регистра.** База должна быть создана в кодировке UTF-8 (скрипт `00_create_database.sql` делает это).
